# Farside 0.2.1 · 控制台、远程连接与可靠执行

这一版把设置页扩展为更完整的 Farside 控制台，同时集中修复更新、任务终态和待确认交互中容易让用户失去判断的问题。

## 升级亮点

- 账户页新增额度加油包、官方 API Key 接入、本机登录设备和模型／工具使用记录。
- 新增“个人资料”，用本机会话统计 Token 活动、连续使用天数、任务纪录、推理偏好及常用技能与工具。
- 配置文件新增按项目管理的 Hooks；新增“连接”模块，可通过 SSH 隧道远程控制另一台机器上的 Kimi 工作区。
- 修复额度耗尽、限流、鉴权失败或服务异常时仍显示“已完成”的问题，并让待确认卡片实时出现。
- 更新系统增加手动检查、版本历史、详细更新日志和安装后自动重启；macOS 更新可自动清除 Farside 的 quarantine 属性。

## 账户与个人资料

### 更完整的账户控制台

- 保留套餐、5 小时窗口与周周期，并新增额度加油包余额、本月消费和额度上限。
- “充值与管理”直接进入 Kimi 官方额度页面。
- 新增 API Keys 卡片，展示已经接入 Farside 的 Kimi 官方 API Provider，并提供官方控制台管理入口。
- 新增登录设备卡片，明确当前 Farside、系统平台、架构、Electron 版本和 Provider 状态；完整设备列表仍由 Kimi 官方控制台管理。
- 新增模型调用与工具调用记录，便于定位近期请求状态和使用来源。

### 本机个人资料

- 展示累计 Token、单任务峰值 Token、最长任务时长、当前连续天数和最长连续天数。
- Token 活动支持每日、每周和累计视图。
- 汇总快速模式占比、最常用推理强度、任务总数、已探索技能和技能调用次数。
- 展示最常使用的 Skills 与 Tools。
- 统计只读取本机 Kimi 会话，不会上传新的个人分析数据。

## 配置文件、Hooks 与连接

### 项目级 Hooks

- 在“设置 → 配置文件”新增 Hooks 管理界面。
- Hooks 以项目为单位保存到 `.farside/hooks.json`，不同工作区互不影响。
- 支持事件、matcher、command、描述和启停状态，并在保存前校验结构与大小。

### Remote / SSH

- 新增 SSH 连接档案，可保存主机、端口、用户、私钥、远程 Kimi 路径、数据目录与服务端口。
- 支持测试握手、建立连接、断开连接、编辑和移除。
- 远程控制通过经过认证的 SSH 隧道工作，两端 Kimi Server 继续只监听回环地址。
- 支持系统 SSH Agent、`~/.ssh/config` 或指定私钥，不读取和保存 SSH 密码。

## 执行可靠性与状态反馈

- 区分真正完成与执行中断；服务端未返回完成信号时不再把 Session 标为“已完成”。
- 对额度不足、限流、登录凭据失效和一般服务错误给出可理解的错误说明。
- 服务端暂时不可达时保持“收尾中”，避免根据连接中断反向猜测任务已经完成。
- 审批和问题卡片收到待处理信号后立即同步，并通过短时重试和 Session snapshot 补偿竞态，不再依赖切换页面刷新。
- 短时深空思考显示实际的短时长，不再轻易退化成“时长未知”。

## 更新与关于

- “设置 → 关于”新增检查更新、仓库地址、当前版本、更新日志与历史版本。
- 启动检查增加 GitHub Release 页面降级通道，匿名 API 受限或网络环境特殊时仍可识别新版本。
- 一键更新显示下载进度并直接打开对应平台安装包。
- Windows 安装器接管后退出旧版本，并在安装完成后启动新版本。
- macOS 会等待 `/Applications/Farside.app` 完成替换，自动运行 `xattr` 清除 quarantine；普通权限不足时请求管理员授权，随后自动重启。
- macOS 的一键更新按钮旁会明确说明上述行为。

## 发布说明改进

- Release 优先读取 `releases/vX.Y.Z.md` 的手写说明。
- 没有手写说明时，生成器会按功能、修复、性能、兼容性和工程维护分类，并保留提交正文中的有效细节。
- 自动附带安装包名称、文件大小、SHA-256 和完整版本对比链接。

## 下载与安装

- Windows：`Farside.Setup.0.2.1.exe`
- macOS Apple Silicon：`Farside-0.2.1-arm64.dmg`

升级前建议结束正在执行的 Agent 任务。安装包不会主动删除本地项目、Kimi 配置、连接档案或会话数据。

> macOS 安装包未使用 Developer ID 签名。一键更新会在安装完成后自动清除 `/Applications/Farside.app` 的 quarantine 属性；必要时 macOS 会显示管理员授权框。

## 发布验证

- `npm test`
- `npm run typecheck`
- `npm run build`
- 校验 Release 工作流和详细说明生成器
- Windows 与 macOS 安装包均成功构建后才创建正式 Release

## 已知限制

- macOS 当前仅提供 Apple Silicon（arm64）安装包。
- Kimi Server 尚未开放完整的云端登录设备和 API Key 管理接口；这两类云端操作会跳转到 Kimi 官方控制台。
- macOS 通过浏览器手动下载和安装时不会启动 Farside 的安装监视器；自动清除 quarantine 与重启仅适用于应用内“一键更新”。
