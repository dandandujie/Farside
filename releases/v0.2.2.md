# Farside 0.2.2 · Kimi Code 0.29.2 Runtime 升级

本版本将 Farside Runtime 从 Kimi Code 0.27.0 升级到 0.29.2，并完成服务生命周期和运行时完整性适配。

## 升级亮点

- 锁定 Kimi Code 0.29.2 六平台 runtime、官方 manifest 与 SHA-256。
- 适配 0.28.1+ 前台 `kimi web --no-open` 生命周期，停止服务不再调用已移除的 `kimi web kill/ps`。
- 保持现有 `/api/v1` REST 与 `/api/v1/ws` 客户端边界，兼容 0.29.2 的 kap-server 后端。
- 0.27/0.28 的历史 harness 补丁已由上游吸收，升级后不再重复应用。
- 补充 0.29.2 上游差异审查与发布前验证记录。

## 发布验证

- `npm test`
- `npm run typecheck`
- `npm run build`
- `npm run runtime:smoke`
- `npm run runtime:upstream:check`

## 已知限制

- GitHub Actions 负责 Windows 与 macOS 安装包构建；当前 macOS 产物仍为 Apple Silicon arm64。
- 正式发布使用官方锁定 runtime；后续如生成 Farside 自有 runtime 产物，需要另行完成六平台产物门禁。
