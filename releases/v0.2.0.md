# Farside 0.2.0 · 交互与稳定性升级

这一版集中改善长任务操作、会话回溯与 Runtime 稳定性，并将随包 Kimi Code Runtime 统一适配到 0.28 系列。

## 升级亮点

- 新增请求队列：Agent 正在执行时仍可继续编写和安排下一条请求，不再因为输入时机丢失工作。
- 新增 Plan 审阅卡：计划型任务可在继续执行前集中查看并确认计划。
- 新增逐轮文件变更与选择性撤销：每轮完成后能看到具体改动，并按范围回退。
- 新增环境摘要：把工作区、Git、Runtime 和会话上下文集中到任务轨迹中。
- 统一 Runtime 供应链并适配 Kimi Code 0.28，增强协议兼容性、校验和异常恢复。

## 交互与会话

### 请求队列

- Agent 忙碌时，新请求会进入可见队列。
- 队列项目可以重新编辑或移除，避免用户不知道下一条请求是否已经提交。
- 会话列表和输入区的执行状态进一步统一。

### Plan 审阅

- 新增独立的 Plan Review 卡片。
- 权限确认、Agent 提问与计划审阅采用一致的待处理交互模式。

### 变更回溯

- 新增每轮文件变更卡片，区分新增、修改与删除。
- 新增选择性撤销界面，可按具体改动范围恢复，而不是只能整体回退一轮。
- 非 Git 工作目录会显示可理解的说明，不再直接暴露原始 Git 错误。

### 任务轨迹

- 新增环境摘要，集中显示工作区和运行环境信息。
- 丰富子代理状态和任务进度显示。
- 优化会话标题栏、终端入口和轨迹布局。

## 账户与更新

- 账户弹层新增“检查更新”，有新版本时直接打开更新弹窗，已是最新版时显示明确结果。
- 更新状态进入共享 Store，避免不同入口显示不一致。
- 设置页默认进入账户模块，减少首次配置后的查找成本。
- 改进 OAuth 登录状态恢复，降低授权流程被刷新或重启打断后的异常概率。

## Runtime 与兼容性

- 随包 Runtime 统一适配 Kimi Code 0.28。
- Runtime 锁文件、上游版本检查和产物校验流程重新整理。
- 增强实际 daemon 地址识别，不再依赖固定端口。
- Runtime 补丁覆盖工具结果 token 预算、REST harness 控制与渐进式内置工具加载。
- 新增上游兼容性检查和 Runtime smoke 验证，协议不匹配时会明确失败。

## 界面细节

- macOS 无边框窗口不再重复显示系统交通灯。
- 优化标题栏、任务输入区、Session 列表与 Diff 面板的状态表达。

## 下载与安装

- Windows：`Farside.Setup.0.2.0.exe`
- macOS Apple Silicon：`Farside-0.2.0-arm64.dmg`

升级前请先结束正在执行的 Agent 任务。安装包不会主动删除本地项目、Kimi 配置或会话数据。

> 当前安装包未进行商业代码签名，Windows 或 macOS 可能显示系统安全提示。

## 发布验证

- Windows 与 macOS 均执行自动化测试和 TypeScript 类型检查。
- 验证 Runtime 锁文件、manifest、上游版本与补丁应用。
- 验证 Kimi Server endpoint 发现、OAuth 状态与逐轮文件变更。
- 两个平台安装包均成功构建并上传后才发布 Release。

## 已知限制

- macOS 当前仅提供 Apple Silicon（arm64）安装包。
- 自动更新仍依赖客户端能够访问 GitHub Releases。
- 未签名安装包首次启动时可能需要在系统安全设置中确认。
